# Site Assets

This directory contains only static website assets for the Body Inc parent-company site.

- `body-studio-250-hudson.webp` is copied from the already-public Body Studio website asset set and used as the full-bleed location image for the parent company route to Body Studio.
- `favicon.svg` and `body-inc-card.svg` are lightweight site-owned SVG assets for browser and Open Graph metadata.

Do not add raw legal files, Delaware filings, sensitive screenshots, production exports, secrets, PHI, or source binaries here.
